
# 25 + 5 Clock

A Pomodoro timer built with React and Vite.

## Features

- Default session length: 25 minutes
- Default break length: 5 minutes
- Increase or decrease session and break lengths
- Start and pause the timer
- Reset the timer to its default values
- Automatically switch between session and break

## Technologies Used

- React
- JavaScript
- CSS
- Vite
